# Starter chord songs and sheet diagrams

- [ ] In Play Along, open Whiskey in the Jar (G, Em, C, D) and Amazing Grace (G, C, D).
- [ ] Open either starter from Chord Sheet Maker's Starter songs menu.
- [ ] Confirm replacing an edited sheet can be canceled; saved sheets remain intact.
- [ ] Save a customized starter as a personal sheet; reopening the starter retains the built-in original.
- [ ] Choose Block diagrams, Line diagrams, and Hidden. The choice survives reopening the page.
- [ ] Repeated chords appear once, in first-use order, above the lyrics.
- [ ] Transpose a sheet and confirm chord labels and guitar shapes update together.
- [ ] Unsupported chord symbols show “diagram unavailable.”
- [ ] Use practice scrolling and print/PDF with either diagram style.
- [ ] Check narrow/mobile layout and light/dark themes.

These are simplified traditional chord-and-lyric arrangements, available without a backend or account. Whiskey uses four easy chords; Amazing Grace uses three. They do not add MIDI melody tracks. Text downloads and songbook backups retain their existing chord/lyric format; diagrams are part of the visual sheet and print output.
